# Z50000 Révision V2

Application Android personnelle de révision technique basée sur le **Livret d'études Z50000 Formation initiale**, ETOF DP04001, version 02 du 17/09/2020.

## Contenu
- 200 questions, 40 par thème
- Généralités & mécanique
- Énergie électrique
- Pneumatique & traction
- Freinage
- Fonctions annexes
- Questions à réponse unique et questions à réponses multiples
- Mode rapide : 10 questions
- Mode entraînement : 20 questions, correction immédiate
- Mode examen : 40 questions, correction à la fin
- Mode expert : 200 questions, correction à la fin
- Référence de page du livret pour chaque question
- Progression locale conservée sur le téléphone

## Important
Le contenu pédagogique est destiné à la révision personnelle et reprend le document source fourni pour cette application. Il ne remplace pas les procédures, consignes ni documents opérationnels applicables.
